# Crisp Kids Studio 🎨

A local-first, offline-capable educational workshop and kids learning assistant built for preschool and elementary learners. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **ABC & 123 Flashcards:** Interactive letters and numbers flashcards to build foundational literacy and numeracy.
- **Magical Doodle Canvas:** A smooth mouse- and touch-friendly drawing pad with multi-color options.
- **Daily Routines & Stars:** Fun daily goal checklist with reward stars and local storage persistence.
- **Playful & Day Themes:** Vibrant dark-starry and bright daylight themes designed for kids.
- **100% Offline & Private:** Runs entirely client-side in your browser with zero login walls or external server tracking.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, learning logic, canvas drawing, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
